Hugo プロジェクトです。主な実行コマンドは以下の通りです：                                                   
  ┌──────────────────────────┬──────────────────────────────────────────┐                                            
  │         コマンド         │                   説明                   │                                            
  ├──────────────────────────┼──────────────────────────────────────────┤                                            
  │ hugo server              │ 開発サーバーを起動（ホットリロード付き） │                                            
  ├──────────────────────────┼──────────────────────────────────────────┤                                            
  │ hugo server -D           │ 下書き記事も含めて開発サーバーを起動     │                                            
  ├──────────────────────────┼──────────────────────────────────────────┤                                            
  │ hugo                     │ 本番用にサイトをビルド（public/ に出力） │                                            
  ├──────────────────────────┼──────────────────────────────────────────┤                                            
  │ hugo new posts/記事名.md │ 新しい記事を作成      
   - draft: true なので、hugo server -D で確認できます                                                                
  - 公開する際は draft: false に変更してください                                │                                            
  └──────────────────────────┴──────────────────────────────────────────┘                                            
  開発中は hugo server を実行すると、http://localhost:1313 でサイトをプレビューできます。
